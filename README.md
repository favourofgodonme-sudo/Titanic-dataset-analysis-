# Titanic-dataset-analysis-
A date analysis cleaned and analyzed in visuals to show the highest survived by age, class,sex and more in the titanic.
I started the analysis with exploration to get to know what it's all about 
My second step was to import the libraries and then I went into understanding the data
at this point after I have understood the data, I cleaned the data by removing, blanks and duplicates 
then I performed the Bivariate, multiverate and univeriate analysis to display the data in visaul forms for better understanding and interpretation of relationship 
finally I wrote my insights, recommendations and executive summary of the data analysis
The dataset was gotten from keggle.com
